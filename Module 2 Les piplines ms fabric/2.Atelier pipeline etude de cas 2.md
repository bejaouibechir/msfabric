# Atelier 2 : Architecture Medallion complète — Bronze → Silver → Gold avec orchestration

## Contexte : Transition urbaine vers une grille énergétique intelligente

Une **ville intelligente** modernise son réseau électrique en déployant 100 capteurs IoT pour monitorer la consommation, détecter les anomalies et réduire les pertes énergétiques.

### 1. État des lieux

Les données brutes arrivent en continu et doivent être nettoyées, enrichies avec des seuils de référence, puis analysées pour détecter les incidents.

- **100 capteurs IoT** déployés dans 4 quartiers
- **7200 relevés** sur 3 jours (données temps réel)
- **50 incidents** détectés automatiquement
- **Données brutes** non structurées nécessitant nettoyage
- **Table de référence** avec seuils d'alerte par type de capteur

### 2. Problématique

**Comment transformer les données IoT brutes (Bronze) en données nettoyées et enrichies (Silver), en détectant les anomalies, en appliquant des règles métier et en bouclant avec Until pour traiter les incidents non résolus ?**

**Contraintes :**
- ✅ Charger d'abord les CSV en tables Bronze
- ✅ Enrichir avec les seuils via un **Lookup** (depuis table)
- ✅ Filtrer les capteurs actifs avec **If Condition**
- ✅ Boucler sur les incidents non résolus avec **Until**
- ✅ Tracer les anomalies détectées

### 3. Solution : Pipeline de transformation intelligent

Pipeline qui :
1. **Charge** les 5 CSV vers tables Bronze (sans `_` ni `-`)
2. **Lit** la table de référence avec **Lookup**
3. **Copie** et **transforme** Bronze → Silver
4. **Filtre** les données valides avec **If Condition**
5. **Boucle** avec **Until** jusqu'à résolution des incidents
6. **Trace** les traitements

## Étapes

### 1. Créer le lakehouse Silver

1. Dans le workspace **WS_Energie_Renouvelable**, cliquez **+ New item**
2. Sélectionnez **Lakehouse**
3. **Name** : `LH_Energie_Silver`
4. Cliquez **Create**

⏳ Attendez la création (15-30 secondes)

---

### 2. Charger les CSV dans Silver/Files

⚠️ **Important** : Les fichiers CSV doivent être dans le lakehouse **Silver**, pas Bronze !

1. Ouvrez **LH_Energie_Silver**
2. Section **Files** → créez un dossier **smartgrid**
3. Uploadez les 5 fichiers CSV dans `LH_Energie_Silver/Files/smartgrid/`

✅ Vérifiez : `Files/smartgrid/` contient les 5 fichiers

💡 **Astuce** : Le pipeline 1 lit depuis Silver/Files et écrit dans Silver/Tables.

---

### 3. Créer le pipeline de chargement initial

1. Dans le workspace, cliquez **+ New item** → **Data pipeline**
2. **Name** : `PL_Chargement_CSV_Bronze`
3. Cliquez **Create**

💡 **Astuce** : Ce pipeline charge les CSV en tables (sans underscore ni tiret).

---

### 4. Charger les 5 CSV en tables

⚠️ **RÈGLE CRITIQUE** : Les noms de tables **NE DOIVENT PAS** contenir `_` ni `-`.

Nous allons créer **5 activités Copy Data** pour charger chaque CSV.

#### Copy 1 - Infrastructures

1. **Activities** → Créer **Copy data Activity**
2. Onglet **General** :
   - **Name** : `ChargerInfrastructures`

**Source** :
- **Connection** : `LH_Energie_Silver`
- **Lakehouse** : `LH_Energie_Silver`
- **Root folder** : **Files**
- **File path** : `smartgrid/infrastructures_existantes.csv`
- **File format** : **DelimitedText**
- **First row as header** : coché

**Destination** :
- **Connection** : `LH_Energie_Silver`
- **Lakehouse** : `LH_Energie_Silver`
- **Root folder** : **Tables**
- **Table** : `infrastructures` (⚠️ sans underscore !)
- **Table action** : **Overwrite**
