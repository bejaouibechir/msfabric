## 📝 Cellule 1 : Import et chargement données Silver

### 🔍 Avant d'exécuter

**Objectif** : Combiner les données enrichies Silver avec les prédictions ML pour créer un dataset unique Gold.

**Tables sources** :

- `silver.consumption_enriched` : Données Silver complètes (baseline, z-score, météo, référentiel)
- `silver.consumption_predictions` : Prédictions ML J+1

**Jointure** : `LEFT JOIN` sur `(hour, site_id)` pour conserver toutes les consommations réelles même sans prédiction.

### 💻 Code

```python
from pyspark.sql import functions as F

# Charger Silver enriched
df_enriched = spark.table("Lakehouse_silver.silver.consumption_enriched")

# Charger prédictions
df_predictions = spark.table("Lakehouse_silver.silver.consumption_predictions")

# Jointure
df = df_enriched.join(
    df_predictions.select("hour", "site_id", 
                          F.col("prediction").alias("predicted_consumption_mw")),
    on=["hour", "site_id"],
    how="left"
).withColumn(
    "prediction_error_mw",
    F.abs(F.col("avg_consumption_mw") - F.col("predicted_consumption_mw"))
)

print(f"📊 Données Silver combinées : {df.count()} lignes")
df.show(5)
```

### 📤 Résultat

```
📊 Données Silver combinées : 148704 lignes
```

*(Aperçu des 5 premières lignes avec toutes les colonnes enrichies)*

### 💡 Interprétation

✅ **148,704 lignes** : Dataset combiné avec :

- Expansion 1:4 due aux prix spot quart-horaires (17,280 × 4 = 69,120 base)
- Multiplication par ~2 due aux duplications dans les jointures

**Pourquoi ce volume ?**

- 17,280 lignes unique horaires Silver
- × 4 prix quart-horaires par heure
- × ~2 duplications diverses jointures
- = ~138,240 lignes (proche de 148,704)

**Colonne clé ajoutée** : `prediction_error_mw` = écart absolu entre réel et prédit (métrique qualité ML).

## 📝 Cellule 2 : Agrégation quotidienne par site

### 🔍 Avant d'exécuter

**Objectif** : Créer une table **daily_consumption_by_site** avec 1 ligne = 1 jour × 1 site.

**Agrégations calculées** :

- Consommation totale journalière (`SUM`)
- Pics journaliers (`MAX`)
- Moyennes baseline, prédictions, température (`AVG`)
- Comptage anomalies (`SUM` conditionnel)

**Utilité** : Table principale pour dashboards Power BI quotidiens.

### 💻 Code

```python
df_daily = df.groupBy(
    F.to_date("hour").alias("date"),
    "site_id",

).agg(
    F.sum("avg_consumption_mw").alias("total_consumption_mwh"),
    F.avg("avg_consumption_mw").alias("avg_consumption_mw"),
    F.max("max_consumption_mw").alias("peak_consumption_mw"),
    F.avg("baseline_7d_mw").alias("avg_baseline_mw"),
```

## 📝 Cellule 5 : Opportunités effacement (Demand Response)

### 🔍 Avant d'exécuter

**Objectif** : Identifier les **opportunités de revenus** via effacement électrique pendant prix spot élevés.

**Logique Demand Response** :

- Sites **flexibles** uniquement (Industrie + Résidentiel flexibles)
- Consommation > 0.5 MW (seuil rentabilité)
- Effacement 30% de la consommation actuelle
- Gain = `(Prix spot - Prix effacement) × MWh effacés`

**Signaux d'action** :

- 🔴 Prix > 300 €/MWh → EFFACEMENT MAX
- 🟠 Prix > 200 €/MWh → EFFACEMENT PARTIEL
- 🟢 Prix < 50 €/MWh → CONSOMMER

### 💻 Code

```python
df_curtailment = df.filter(F.col("flexible") == True).filter(F.col("avg_consumption_mw") > 0.5)

df_curtailment = df_curtailment.withColumn(
    "ratio_vs_baseline",
    F.round(F.col("avg_consumption_mw") / F.col("baseline_7d_mw"), 2)
).withColumn(
    "curtailment_potential_mw",
    F.round(F.col("avg_consumption_mw") * 0.3, 3)  # 30% effacement
).withColumn(
    "potential_gain_eur",
    F.when(
        F.col("price_eur_mwh") > F.col("curtailment_price_eur_mwh"),
        F.round((F.col("avg_consumption_mw") * 0.3) * 
                (F.col("price_eur_mwh") - F.col("curtailment_price_eur_mwh")), 2)
    ).otherwise(0)
).withColumn(
    "action_signal",
    F.when((F.col("price_eur_mwh") > 300) & (F.col("flexible") == True), "🔴 EFFACEMENT MAX")
     .when((F.col("price_eur_mwh") > 200) & (F.col("flexible") == True), "🟠 EFFACEMENT PARTIEL")
     .when((F.col("price_eur_mwh") < 50) & (F.col("flexible") == True), "🟢 CONSOMMER")
     .otherwise("Aucune action")
)

df_curtailment = df_curtailment.select(
    "hour", "site_id", "site_type", "flexible", "curtailment_price_eur_mwh",
    "avg_consumption_mw", "baseline_7d_mw", "ratio_vs_baseline",
    "price_eur_mwh", "curtailment_potential_mw", "potential_gain_eur", "action_signal"
).orderBy(F.desc("potential_gain_eur"))

df_curtailment.write.mode("overwrite").format("delta").saveAsTable("gold.curtailment_opportunities")
print(f"✅ Table gold.curtailment_opportunities créée : {df_curtailment.count()} lignes")
df_curtailment.filter("potential_gain_eur > 0").show(10)
```

## 📝 Cellule 7 : Table alertes actives

### 🔍 Avant d'exécuter

**Objectif** : Table **active_alerts** pour dashboard opérationnel temps réel.

**Critères d'alerte** :

- Anomalie détectée (z-score > 3)
- Prix spot > 300 €/MWh
- Erreur prédiction > 1.0 MW

**Priorités** :

- **CRITIQUE** : Anomalie + Prix élevé (double risque)
- **HAUTE** : Anomalie OU Prix élevé
- **MOYENNE** : Erreur prédiction

### 💻 Code

```python
df_alerts = df.filter(
    (F.col("anomaly") == "⚠️ ANOMALIE") |
    (F.col("price_eur_mwh") > 300) |
    (F.col("prediction_error_mw") > 1.0)
)

df_alerts = df_alerts.withColumn(
    "alert_type",
    F.when(F.col("anomaly") == "⚠️ ANOMALIE", "Consommation anormale")
     .when(F.col("price_eur_mwh") > 300, "Prix spot très élevé")
     .when(F.col("prediction_error_mw") > 1.0, "Erreur prédiction élevée")
     .otherwise("Autre")
).withColumn(
    "priority",
    F.when((F.col("anomaly") == "⚠️ ANOMALIE") & (F.col("price_eur_mwh") > 300), "CRITIQUE")
     .when((F.col("anomaly") == "⚠️ ANOMALIE") | (F.col("price_eur_mwh") > 300), "HAUTE")
     .when(F.col("prediction_error_mw") > 1.0, "MOYENNE")
     .otherwise("BASSE")
)

df_alerts = df_alerts.select(
    F.col("hour").alias("alert_time"),
    "site_id", "site_type", "alert_type",
    "avg_consumption_mw", "baseline_7d_mw", "predicted_consumption_mw",
    "price_eur_mwh", "priority"
).orderBy(
    F.when(F.col("priority") == "CRITIQUE", 1)
     .when(F.col("priority") == "HAUTE", 2)
     .when(F.col("priority") == "MOYENNE", 3)
     .otherwise(4),
    F.desc("alert_time")
)

df_alerts.write.mode("overwrite").format("delta").saveAsTable("gold.active_alerts")
print(f"✅ Table gold.active_alerts créée : {df_alerts.count()} lignes")
df_alerts.filter("priority IN ('CRITIQUE', 'HAUTE')").show(10)
```

```DAX
ADDCOLUMNS(
    CALENDAR(DATE(2025, 1, 1), DATE(2025, 12, 31)),
    "Year", YEAR([Date]),
    "Month", FORMAT([Date], "MMM"),
    "MonthNum", MONTH([Date]),
    "Quarter", "Q" & FORMAT([Date], "Q"),
    "WeekDay", FORMAT([Date], "ddd"),
    "WeekNum", WEEKNUM([Date]),
    "IsWeekend", WEEKDAY([Date]) IN {1, 7}
)
```

### 📊 Étape 3 : Mesures DAX essentielles

Créer ces **mesures** dans une table `_Measures` :

#### A. Mesures de consommation

```DAX
Total Consumption MWh = 
SUM(daily_consumption_by_site[total_consumption_mwh])

Avg Daily Consumption = 
AVERAGE(daily_consumption_by_site[total_consumption_mwh])

Peak Consumption MW = 
MAX(daily_consumption_by_site[peak_consumption_mw])

% vs Baseline = 
DIVIDE(
    SUM(daily_consumption_by_site[total_consumption_mwh]),
    SUM(daily_consumption_by_site[avg_baseline_mw]) * 24,
    0
) * 100 - 100
```

#### B. Mesures d'anomalies

```DAX
Total Anomalies = 
SUM(daily_consumption_by_site[nb_anomalies])

Anomaly Rate % = 
DIVIDE(
    [Total Anomalies],
    SUM(daily_consumption_by_site[nb_measurements]),
    0
) * 100

Critical Alerts = 
COUNTROWS(
    FILTER(active_alerts, active_alerts[priority] = "CRITIQUE")
)
```

#### C. Mesures financières

```DAX
Total Curtailment Gain € = 
SUM(curtailment_opportunities[potential_gain_eur])

Avg Electricity Price = 
AVERAGE(daily_consumption_by_site[avg_price_eur_mwh])

Peak Price Reached = 
MAX(daily_consumption_by_site[peak_price_eur_mwh])

Potential Annual Savings = 
[Total Curtailment Gain €] * 12
```

#### D. Mesures de performance ML

```DAX
Avg Prediction Error % = 
AVERAGE(site_kpis[prediction_error_pct])

Best Predicted Site = 
TOPN(
    1,
    VALUES(site_kpis[site_id]),
    [Avg Prediction Error %],
    ASC
)
```

**Pourquoi ?** Si Lakehouse indisponible, Power BI bascule sur dernier import.
