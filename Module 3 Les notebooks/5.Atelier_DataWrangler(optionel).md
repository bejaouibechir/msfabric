# Atelier : Data Wrangler

**But pédagogique** : utiliser l'interface visuelle Data Wrangler dans un notebook Fabric pour explorer, nettoyer et transformer des données, puis récupérer le code Python généré automatiquement.

---

## Contexte et données

Le fichier source est **`consumption_raw.csv`** — données de consommation électrique brutes avec plusieurs problèmes de qualité intentionnels :

| Problème                | Exemple                                                             |
| ----------------------- | ------------------------------------------------------------------- |
| Formats de dates mixtes | `2025-01-03T04:30:00`, `17/01/2025 18:15:00`, `2025-01-22 01:00:00` |
| Valeur manquante        | `consumption_mw` vide sur la ligne `SITE_COM_001 / ERROR`           |
| Statut anormal          | `status = ERROR`                                                    |

---

## Partie 1 — Préparer l'environnement

### 1.1 — Charger le fichier dans le Lakehouse

1. Ouvrir [https://app.fabric.microsoft.com](https://app.fabric.microsoft.com)
2. Ouvrir votre workspace
3. Créer un **Lakehouse** nommé **`lakehouse`** (ou utiliser un existant)
4. Dans le Lakehouse, ouvrir **Files**
5. Cliquer **Upload** → sélectionner **`consumption_raw.csv`**

**Ce que vous devez voir à l'écran** :

- `consumption_raw.csv` visible dans **Files**

---

### 1.2 — Créer le notebook et charger les données

1. Dans le workspace, cliquer **+ New item** → **Notebook**
2. Nommer le notebook **`nb_datawrangler_demo`**
3. Attacher le Lakehouse **`lakehouse`**
4. Dans la première cellule, coller le code suivant :

```python
df = (
    spark.read
    .option("header", True)
    .option("inferSchema", False)
    .csv("Files/consumption_raw.csv")
    .toPandas()
)

display(df)
```

5. Exécuter la cellule

**Ce que vous devez voir à l'écran** :

- un tableau avec les colonnes : `timestamp`, `site_id`, `consumption_mw`, `voltage_v`, `frequency_hz`, `status`
- des formats de dates hétérogènes dans la colonne `timestamp`
- une ligne avec `consumption_mw` vide et `status = ERROR`

---

## Partie 2 — Ouvrir Data Wrangler

1. Cliquer sur la cellule contenant `df`
2. Dans le menu du notebook, cliquer **Data** dans la barre d'outils
3. Sélectionner **Launch Data Wrangler**
4. Choisir le DataFrame **`df`** dans la liste

**Ce que vous devez voir à l'écran** :

- l'interface Data Wrangler s'ouvre
- le panneau gauche affiche les **opérations disponibles**
- le panneau central affiche l'**aperçu des données**
- le panneau droit affiche le **résumé statistique** par colonne

> 💡 **Astuce** : Data Wrangler détecte automatiquement les anomalies — les colonnes avec valeurs manquantes sont surlignées en orange.

## Partie 3 — Explorer les données

### 3.1 — Résumé des colonnes

Dans le panneau de droite, observer pour chaque colonne :

| Colonne          | Ce que Data Wrangler signale                         |
| ---------------- | ---------------------------------------------------- |
| `timestamp`      | type `object` (string) — pas encore parsé comme date |
| `consumption_mw` | 1 valeur manquante                                   |
| `status`         | 2 valeurs distinctes : `OK` et `ERROR`               |

### 3.2 — Identifier la ligne problématique

1. Dans l'aperçu central, cliquer sur l'en-tête **`consumption_mw`**
2. Data Wrangler surligne la cellule vide
3. Observer que cette ligne correspond à `status = ERROR`

---

## Partie 4 — Nettoyer les données avec Data Wrangler

### 4.1 — Supprimer les lignes ERROR

1. Dans le panneau gauche, chercher **Filter**
2. Sélectionner **Filter rows**
3. Configurer :

| Champ         | Valeur         |
| ------------- | -------------- |
| **Column**    | `status`       |
| **Condition** | `Not equal to` |
| **Value**     | `ERROR`        |

4. Cliquer **Apply**

**Ce que vous devez voir à l'écran** :

- la ligne avec `status = ERROR` disparaît de l'aperçu
- le compteur de lignes diminue de 1

---

### 4.2 — Convertir consumption_mw en numérique

1. Dans le panneau gauche, chercher **Change column type**
2. Sélectionner la colonne **`consumption_mw`**
3. Choisir le type **`Decimal (float64)`**
4. Cliquer **Apply**

---

### 4.3 — Standardiser la colonne timestamp

> ⚠️ **Piège** : la conversion **Change column type → DateTime** génère `df.astype({'timestamp': 'datetime64[ns]'})` qui échoue sur des formats mixtes comme ceux de ce fichier (`2025-01-03T04:30:00`, `17/01/2025 18:15:00`, `2025-01-22 01:00:00`). Il faut utiliser un **Custom transform**.

1. Dans le panneau gauche, chercher **Custom transform**
2. Cliquer **Custom transform**
3. Dans l'éditeur de code qui s'ouvre, saisir :

```python
import pandas as pd
df['timestamp'] = pd.to_datetime(df['timestamp'], format='mixed', dayfirst=True)
```

4. Cliquer **Apply**

**Ce que vous devez voir à l'écran** :

- toutes les dates s'affichent dans un format uniforme `YYYY-MM-DD HH:MM:SS`
- aucune erreur dans le panneau du bas
- l'opération apparaît dans **Cleaning steps** sous le nom `Custom transform`

> 💡 **Explication** : `format='mixed'` indique à pandas d'inférer le format ligne par ligne, ce qui gère les trois formats présents dans le fichier. `dayfirst=True` assure la bonne interprétation des dates au format `dd/MM/yyyy`.

---

### 4.4 — Renommer les colonnes (optionnel)

1. Dans le panneau gauche, chercher **Rename column**
2. Renommer `consumption_mw` en `consumption_MW`
3. Cliquer **Apply**

---

## Partie 5 — Récupérer le code généré

Data Wrangler génère automatiquement le code Python de toutes les opérations effectuées.

1. Cliquer le bouton **Add code to notebook** en haut à droite
2. Data Wrangler insère une nouvelle cellule dans le notebook avec le code complet

**Exemple de code généré** :

```python
# Code generated by Data Wrangler for pandas DataFrame
import pandas as pd

def clean_data(df):
    # Filter rows based on column: 'status'
    df = df[df['status'] != "ERROR"]
    # Change column type to float64 for column: 'consumption_mw'
    df = df.astype({'consumption_mw': 'float64'})
    df['timestamp'] = pd.to_datetime(df['timestamp'], format='mixed', dayfirst=True)
    # Rename column 'consumption_mw' to 'consumption_MW'
    df = df.rename(columns={'consumption_mw': 'consumption_MW'})
    return df

df_clean = clean_data(df.copy())
display(df_clean)
```

> 💡 **Intérêt majeur** : le code est **réutilisable et versionnable**. Il peut être commité dans GitHub et intégré dans un pipeline de production.

## Partie 6 — Sauvegarder le résultat dans le Lakehouse

Ajouter une cellule pour sauvegarder le DataFrame nettoyé en table Delta :

```python
from pyspark.sql import SparkSession

spark_df = spark.createDataFrame(df_clean)

spark_df.write.mode("overwrite").format("delta").saveAsTable("bronze_consumption")
```

Exécuter la cellule et vérifier dans le Lakehouse que la table **`bronze_consumption`** apparaît sous **Tables**.

## Récapitulatif des opérations Data Wrangler

| Opération                     | Effet                                      |
| ----------------------------- | ------------------------------------------ |
| Filter rows                   | Suppression des lignes `ERROR`             |
| Change column type → float    | `consumption_mw` exploitable numériquement |
| Change column type → DateTime | `timestamp` unifié et parsable             |
| Add code to notebook          | Code Python propre et réutilisable généré  |

> 💡 **Bonne pratique** : Data Wrangler est idéal pour la phase d'exploration et de nettoyage initial. Le code généré sert ensuite de base solide pour construire la couche Bronze d'un Lakehouse.
