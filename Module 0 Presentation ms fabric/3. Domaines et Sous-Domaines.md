# Atelier : Domaines et Sous-Domaines

## Partie 1 — Créer le domaine

1. Cliquer sur l'engrenage **⚙️** en haut à droite → **Admin portal**
2. Dans le menu gauche, cliquer **Domains**
3. Cliquer **Start from scratch**
4. Renseigner :

| Champ             | Valeur        |
| ----------------- | ------------- |
| **Name**          | `EnergiaNord` |
| **Domain admins** | `Dev`         |

5. Cliquer **Create**

**Ce que vous devez voir à l'écran** :

- le domaine `EnergiaNord` apparaît dans la liste

---

## Partie 2 — Créer les sous-domaines

### 2.1 — Sous-domaine Finance

1. Cliquer sur le domaine **`EnergiaNord`**
2. Cliquer le button  **New subdomain**
3. Renseigner :

| Champ    | Valeur    |
| -------- | --------- |
| **Name** | `Finance` |

4. Cliquer **Create**

### 2.2 — Sous-domaine Marketing

1. Cliquer à nouveau **+ Create subdomain**
2. Renseigner :

| Champ    | Valeur      |
| -------- | ----------- |
| **Name** | `Marketing` |

3. Cliquer **Create**

**Ce que vous devez voir à l'écran** :

- le domaine `EnergiaNord` avec deux sous-domaines : `Finance` et `Marketing`

---

## Partie 3 — Créer les workspaces

### 3.1 — Workspace Finance

1. Aller sur [https://app.fabric.microsoft.com](https://app.fabric.microsoft.com)
2. Dans la barre latérale gauche, cliquer **Workspaces** → **+ New workspace**
3. Renseigner :

| Champ           | Valeur                            |
| --------------- | --------------------------------- |
| **Name**        | `WS_FINANCE`                      |
| **Description** | `Workspace Finance - EnergiaNord` |

4. Chosissez le sous domaine finance du champ Domains
5. Chosissez la capacité du chmaps capacité
6. Cliquer **Apply**

### 3.2 — Workspace Marketing

1. Cliquer **+ New workspace**
2. Renseigner :

| Champ           | Valeur                              |
| --------------- | ----------------------------------- |
| **Name**        | `WS_MARKETING`                      |
| **Description** | `Workspace Marketing - EnergiaNord` |

3. Cliquer **Apply**

---

## Partie 4 — Rattacher les workspaces aux sous-domaines

### Option A — depuis le portail Admin (recommandée)

1. Retourner dans **Admin portal** → **Domains**
2. Cliquer sur le domaine **`EnergiaNord`**
3. Cliquer sur le sous-domaine **`Finance`**
4. Cliquer **Assign workspaces**
5. Rechercher et sélectionner **`WS_FINANCE`**
6. Cliquer **Assign**
7. Répéter pour le sous-domaine **`Marketing`** → assigner **`WS_MARKETING`**

### Option B — depuis les Workspace settings

1. Ouvrir le workspace **`WS_FINANCE`**
2. Cliquer **Workspace settings** → **General**
3. Dans le champ **Domain**, sélectionner `EnergiaNord / Finance`
4. Cliquer **Apply**
5. Répéter pour **`WS_MARKETING`** → sélectionner `EnergiaNord / Marketing`

**Ce que vous devez voir à l'écran** :

- `WS_FINANCE` rattaché au sous-domaine `Finance`
- `WS_MARKETING` rattaché au sous-domaine `Marketing`
- dans le portail Admin, les deux workspaces apparaissent sous leur sous-domaine respectif

---

## Partie 5 — Vérifier l'organisation

1. Aller dans **Admin portal** → **Domains**
2. Ouvrir `EnergiaNord`

**Ce que vous devez voir** :

```
EnergiaNord (domaine)
├── Finance (sous-domaine)
│   └── WS_FINANCE
└── Marketing (sous-domaine)
    └── WS_MARKETING
```

> 💡 **Intérêt** : les domaines permettent de déléguer l'administration, d'appliquer des politiques de données (certification, sensibilité) et de filtrer le catalogue de données par métier dans Microsoft Purview.

⚠️ **Piège** : un workspace ne peut appartenir qu'à **un seul domaine/sous-domaine** à la fois. Si vous réassignez un workspace, il quitte automatiquement son domaine précédent.
