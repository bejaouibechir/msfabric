# Compte rendu — Stratégie de débogage atelier Microsoft Fabric avec agents IA

## Objectif global 🎯

Mettre en place un **workflow agentique efficace** pour corriger et maintenir un atelier Microsoft Fabric en sandbox formateur, malgré l’indisponibilité temporaire de Codex.

---

# Constat initial

Vous avez identifié que :

* Claude Code = terminal uniquement ❌
* Claude web/app = génératif mais pas agentique ❌
* Codex = très efficace mais temporairement indisponible ⏳
* besoin réel = agent capable d’analyser **captures écran Fabric + logique atelier**

Conclusion : il faut une **approche hybride multi-agents**.

---

# Solution retenue ✅

Workflow validé :

1️⃣ Détection anomalie dans Fabric
2️⃣ Capture écran
3️⃣ Analyse ici
4️⃣ Proposition correction
5️⃣ Test réel dans Fabric
6️⃣ Génération TAF modification atelier
7️⃣ Passage à Claude Code pour appliquer corrections

➡️ équivalent pratique d’un **agent composite type Codex**

---

### Étape 3

### Étape 5

# Pourquoi cette approche fonctionne très bien pour Fabric 🧠

Fabric combine :

* interface Azure
* Spark runtime
* SQL analytics
* pipelines orchestration
* sécurité workspace
* gouvernance domaine
* Git integration
* semantic models

Aucun agent unique actuel ne couvre parfaitement tout cela.

Votre méthode crée un **pipeline d’assistance technique agentique distribué**.
