Atelier 2 – Calcul d'Empreinte Carbone et Reporting ESG

Atelier Dataflow Gen2 - Calcul d'Empreinte Carbone et Reporting ESG

📌 Introduction

Contexte

Vous êtes data analyst chez GreenCorp Energy, un producteur d'énergie multi-sources qui doit respecter les réglementations ESG (Environmental, Social, Governance) européennes.

Objectif de l'atelier : Créer un pipeline automatisé pour calculer l'empreinte carbone du mix énergétique et générer des rapports ESG réglementaires.

⚠️ Problématique

3 défis majeurs

1. Calcul d'empreinte carbone impossible

  • Production et facteurs d'émission dans des fichiers séparés
  • Pas de lien automatique source → émissions CO2
  • Impact : Impossible de calculer les émissions totales en temps réel

2. Données sales empêchent le reporting

  • Doublons → Surestimation des émissions
  • Codes erreur -999 → Calculs faussés
  • Dates incohérentes → Impossible de croiser consommation/production

3. Pas de pilotage des objectifs ESG

  • Pas de vue consolidée mix énergétique vs objectifs 2030
  • Calculs manuels dans Excel → Erreurs + 2 jours de retard
  • Risque réglementaire : Amendes si non-conformité EU Green Deal

💡 Comment Dataflow Gen2 résout ces problèmes

Solution proposée

Besoin Solution Dataflow Gen2
Calcul émissions CO2 Jointure production × facteurs_emission
Nettoyer données Filtrage codes erreur + suppression doublons
Unifier dates Transformation DD/MM/YYYY → YYYY-MM-DD
Enrichir contexte Jointure météo + prix CO2 + objectifs ESG
Piloter objectifs Colonnes calculées (écart vs cible, coût carbone)

Architecture cible

6 sources CSV → Dataflow Gen2 → Lakehouse → Power BI Dashboard ESG
                     ↓
         [Nettoyage + Calculs + Jointures]
                     ↓
         Pipeline (refresh quotidien)

ÉTAPE 1 : Créer le Dataflow Gen2

1.1 Initialisation

  1. Workspace → + New → Dataflow Gen2
  2. Nom : DF_Calcul_Empreinte_Carbone_ESG

1.2 Ingestion des 6 sources

  1. Get data → OneLake data hub
  2. Naviguer : Lakehouse → Files → data_esg
  3. Sélectionner les 6 fichiers CSV
  4. Create → Power Query Editor

ÉTAPE 2 : Nettoyage des données

2.1 Requête production_sources_energie

Actions :

  1. Home → Remove Duplicates (toutes colonnes)
  2. Home → Filter Rows → production_kwh ≠ -999
  3. Home → Remove Rows → Remove Errors (production_kwh)
  4. Transform → Data Type : date → Date

Résultat : ~2,300 → ~2,070 lignes (-10% de données invalides)

2.2 Requête consommation_secteurs

Actions :

  1. Transform → Data Type : date_releve → Date
    - Power Query gère automatiquement DD/MM/YYYY et YYYY-MM-DD
  2. Transform → Rename : date_releve → date

Résultat : Dates unifiées

2.3 Requêtes de référence (pas de nettoyage)

  • facteurs_emission_reference
  • meteo_quotidienne
  • objectifs_esg_reglementaires
  • prix_certificats_co2

→ Données propres, juste vérifier les types

ÉTAPE 3 : Calcul des émissions CO2

3.1 Enrichir production avec facteurs d'émission

  1. Sélectionner production_sources_energie
  2. Home → Merge Queries → Merge Queries as New
  3. Configuration :
    - Table gauche : production_sources_energie
    - Table droite : facteurs_emission_reference
    - Colonnes : source_energie = source_energie
    - Join : Left Outer
  4. Nom : production_avec_emissions
  5. Cliquer ⇄ → Sélectionner :
    - facteur_emission_kgco2_kwh
    - categorie
    - objectif_2030_pct

3.2 Calculer les émissions CO2

Add Column → Custom Column :

Nom : emissions_co2_kg
Formule : [production_kwh] * [facteur_emission_kgco2_kwh]

Add Column → Custom Column :

Nom : emissions_co2_tonnes
Formule : [emissions_co2_kg] / 1000

ÉTAPE 4 : Enrichissement contextuel

4.1 Ajouter les données météo

  1. Sélectionner production_avec_emissions
  2. Merge Queries as New :
    - Droite : meteo_quotidienne
    - Colonnes : date = date
    - Join : Left Outer
  3. Nom : production_enrichie_meteo
  4. Expand : temperature_moy_c, ensoleillement_heures, vitesse_vent_mps

4.2 Ajouter les prix CO2

  1. Merge Queries (sur production_enrichie_meteo) :
    - Droite : prix_certificats_co2
    - Colonnes : date = date
    - Join : Left Outer
  2. Expand : prix_tonne_co2_eur

4.3 Calculer le coût carbone

Add Column → Custom Column :

Nom : cout_carbone_eur
Formule : [emissions_co2_tonnes] * [prix_tonne_co2_eur]

ÉTAPE 5 : Agrégation et KPIs

5.1 Créer une vue agrégée quotidienne

  1. Dupliquer production_enrichie_meteo → Nom : emissions_quotidiennes
  2. Transform → Group By :
    - Grouper par : date, categorie
    - Agrégations :
    • production_totale_kwh = Sum(production_kwh)
    • emissions_totales_tonnes = Sum(emissions_co2_tonnes)
    • cout_carbone_total_eur = Sum(cout_carbone_eur)

5.2 Calculer la part renouvelable

Add Column → Custom Column :

Nom : part_renouvelable_pct
Formule : 
let
    prod_renouvelable = if [categorie] = "Renouvelable" then [production_totale_kwh] else 0,
    prod_totale = List.Sum(#"Grouped Rows"[production_totale_kwh])
in
    (prod_renouvelable / prod_totale) * 100

Simplification si trop complexe : Créer 2 requêtes séparées (Renouvelable/Fossile) et calculer dans Power BI

ÉTAPE 6 : Jointure avec objectifs ESG

6.1 Ajouter la colonne année

Sur emissions_quotidiennes :

Add Column → Custom Column :

Nom : annee
Formule : Date.Year([date])

6.2 Jointure avec objectifs

  1. Merge Queries :
    - Droite : objectifs_esg_reglementaires
    - Colonnes : annee = annee
    - Join : Left Outer
  2. Expand :
    - reduction_emissions_pct
    - part_renouvelable_cible_pct
    - emissions_max_tonnes_co2

6.3 Calculer les écarts vs objectifs

Add Column → Custom Column :

Nom : ecart_objectif_emissions_pct
Formule : ([emissions_totales_tonnes] / ([emissions_max_kg_co2] / 1000)) * 100

Add Column → Custom Column :

Nom : conforme_objectif
Formule : if [ecart_objectif_emissions_pct] <= 0 then "✅ Conforme" else "❌ Non conforme"

ÉTAPE 7 : Traiter la consommation

7.1 Nettoyer consommation_secteurs

Déjà fait (dates unifiées)

7.2 Agréger par date

  1. Dupliquer → Nom : consommation_quotidienne
  2. Group By :
    - Grouper par : date
    - Agrégations :
    • consommation_totale_kwh = Sum(consommation_kwh)
    • nombre_sites_total = Sum(nombre_sites)

7.3 Jointure production/consommation (optionnel)

Pour calculer le taux de couverture :

  1. Merge production_enrichie + consommation_quotidienne (sur date)
  2. Calculer : taux_couverture = production / consommation

ÉTAPE 8 : Configuration des destinations

8.1 Table principale : emissions_carbone_detaillees

  1. Sélectionner production_enrichie_meteo (avec tous les enrichissements)
  2. Add data destination → Lakehouse
  3. Configuration :
    - Table : emissions_carbone_detaillees
    - Update method : Append

8.2 Table agrégée : emissions_quotidiennes_kpi

  1. Sélectionner emissions_quotidiennes
  2. Add data destination → Lakehouse
  3. Configuration :
    - Table : emissions_quotidiennes_kpi
    - Update method : Replace

8.3 Table consommation

  1. Sélectionner consommation_quotidienne

  2. Add data destination → Lakehouse

  3. Configuration :

  • Table : consommation_par_secteur
  • Update method : Append
  1. Publish

ÉTAPE 9 : Test et validation

9.1 Premier refresh

  1. Workspace → Dataflow → Refresh now
  2. Durée attendue : 3-4 minutes

9.2 Validation dans Lakehouse

-- 1. Vérifier les émissions totales
SELECT 
    SUM(emissions_co2_tonnes) as emissions_totales_tonnes,
    AVG(prix_tonne_co2_eur) as prix_moyen_co2
FROM emissions_carbone_detaillees;

-- Résultat attendu : ~400,000 tonnes CO2 pour 2025

-- 2. Vérifier la part renouvelable
SELECT 
    categorie,
    SUM(production_kwh) as production_totale,
    ROUND(SUM(production_kwh) * 100.0 / SUM(SUM(production_kwh)) OVER(), 2) as part_pct
FROM emissions_carbone_detaillees
GROUP BY categorie;

-- Résultat attendu :
-- Renouvelable : ~45%
-- Fossile      : ~55%

-- 3. Vérifier conformité objectifs
SELECT 
    date,
    emissions_totales_tonnes,
    emissions_max_tonnes_co2,
    conforme_objectif
FROM emissions_quotidiennes_kpi
WHERE conforme_objectif = '❌ Non conforme'
LIMIT 10;

ÉTAPE 10 : Pipeline d'orchestration

10.1 Créer le Pipeline

  1. Workspace → + New → Data pipeline
  2. Nom : Pipeline_Daily_ESG_Carbon_Reporting

10.2 Activités

  1. Dataflow : DF_Calcul_Empreinte_Carbone_ESG
  2. Send email (On Success) : "✅ Rapport ESG mis à jour"
  3. Send email (On Failure) : "❌ Échec calcul ESG"

10.3 Planification

  • Repeat : Daily
  • Time : 07:00 (après arrivée des données)

10.4 Gestion d'erreurs

  • Retry : 3
  • Retry interval : 60 seconds

Données sales              →    100% propres
Format Excel manuel        →    Pipeline automatisé
Retard de 2 jours          →    Dashboard J+1

KPIs ESG créés

1. Empreinte carbone

  • Emissions totales 2025 : ~400,000 tonnes CO2
  • Coût carbone : ~400,000 t × 85 €/t = 34 M€
  • Par source :
  • Charbon : 35% des émissions (mais 25% de production)
  • Gaz : 45% des émissions (33% de production)
  • Renouvelables : 20% des émissions (42% de production)

2. Mix énergétique

  • Part renouvelable : 45% (objectif 2025 : 40%) ✅
  • Part fossile : 55% (à réduire à 10% d'ici 2030)

3. Conformité réglementaire

  • Objectif émissions 2025 : 500,000 t CO2 max
  • Réalisé : 400,000 t CO2
  • Écart : -20% ✅ Conforme EU Green Deal

Valeur métier

Gains quantifiables :

  • ⏱️ Temps économisé : 2 jours/mois × 12 = 24 jours/an de reporting manuel éliminé
  • 💰 Optimisation mix : Identifier que le charbon émet 2× plus que le gaz pour production équivalente → Stratégie de sortie du charbon en priorité
  • 📊 Transparence ESG : Reporting automatique pour investisseurs et régulateurs
  • 🎯 Pilotage objectifs : Suivi en temps réel de l'écart vs cibles 2030

Décisions stratégiques permises :

  1. Prioriser sortie du charbon (35% émissions, seulement 25% production)
  2. Augmenter solaire/éolien (production déjà à 30%, peut passer à 50%)
  3. Acheter certificats CO2 si dépassement prévu (alerte anticipée)
  4. Négocier prix énergie verte avec visibilité coût carbone évité
