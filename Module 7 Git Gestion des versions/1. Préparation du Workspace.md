**URL attendue :**


**Ce que vous devez voir à l'écran** :

- un dépôt Git vide ou quasi vide
- l'URL HTTPS du dépôt

⚠️ **Piège** : Fabric a besoin d'un vrai dépôt accessible. Si vous n'avez pas les droits sur le projet Azure DevOps, la connexion Git côté Fabric échouera plus tard.

**Ce que vous devez voir à l'écran** :

> 💡 **Astuce** : dans cet atelier de préparation, vous n'avez besoin que de `main` et `develop`. Les branches `feature`, `bugfix` et `hotfix` seront créées dans l'atelier des scénarios.

2. Coller le code suivant :

```python
from pyspark.sql.functions import col, to_timestamp

readings_path = "Files/input/energy/equipment_readings.csv"
reference_path = "Files/input/energy/equipment_reference.csv"

readings_df = (
    spark.read.option("header", True)
    .option("inferSchema", True)
    .csv(readings_path)
    .withColumn("ReadingTime", to_timestamp(col("ReadingTime")))
)

reference_df = (
    spark.read.option("header", True)
    .option("inferSchema", True)
    .csv(reference_path)
)

readings_df.write.mode("overwrite").format("delta").saveAsTable("bronze_equipment_readings")
reference_df.write.mode("overwrite").format("delta").saveAsTable("ref_equipment")

display(readings_df)
```

## Partie 6 — Créer le notebook de transformation

### 6.1 — Créer le notebook

1. Dans le workspace **DEV**, cliquer **+ New item**
2. Rechercher **Notebook**
3. Nom : **`nb_02_transform_equipment_health`**
4. Cliquer **Create**
5. Attacher le Lakehouse **`lh_energy_ops`**

### 6.2 — Ajouter le code de transformation

1. Vérifier que la cellule est en **PySpark**
2. Coller le code suivant :

```python
from pyspark.sql.functions import col, lit, round, when

readings_df = spark.table("bronze_equipment_readings")
reference_df = spark.table("ref_equipment").select(
    "EquipmentId",
    "EquipmentName",
    "Region",
    "NominalPowerKW",
    "CriticalTemperatureC",
    "CriticalVibrationMmS",
)

health_df = (
    readings_df.alias("r")
    .join(reference_df.alias("e"), on="EquipmentId", how="left")
    .withColumn("LoadPct", round((col("PowerKW") / col("NominalPowerKW")) * 100, 2))
    .withColumn(
        "TemperatureStatus",
        when(col("TemperatureC") >= col("CriticalTemperatureC"), lit("CRITICAL"))
        .when(col("TemperatureC") >= col("CriticalTemperatureC") - 10, lit("WARNING"))
        .otherwise(lit("NORMAL")),
    )
    .withColumn(
        "VibrationStatus",
        when(col("VibrationMmS") >= col("CriticalVibrationMmS"), lit("CRITICAL"))
        .when(col("VibrationMmS") >= col("CriticalVibrationMmS") * 0.75, lit("WARNING"))
        .otherwise(lit("NORMAL")),
    )
    .withColumn(
        "HealthStatus",
        when((col("TemperatureStatus") == "CRITICAL") | (col("VibrationStatus") == "CRITICAL"), lit("CRITICAL"))
        .when((col("TemperatureStatus") == "WARNING") | (col("VibrationStatus") == "WARNING"), lit("WARNING"))
        .otherwise(lit("NORMAL")),
    )
)

health_df.write.mode("overwrite").format("delta").saveAsTable("gold_equipment_health")

display(
    health_df.select(
        "EquipmentId",
        "EquipmentName",
        "Site",
        "EnergyType",
        "PowerKW",
        "LoadPct",
        "TemperatureC",
        "VibrationMmS",
        "HealthStatus",
    )
)
```

### 6.3 — Exécuter et vérifier

1. Cliquer **Run all**
2. Attendre la fin de l'exécution
3. Ouvrir le Lakehouse **`lh_energy_ops`**
4. Aller dans **Tables**
5. Vérifier la présence de **`gold_equipment_health`**
6. Ouvrir l'aperçu de la table

**Ce que vous devez voir à l'écran** :

- des équipements en `NORMAL`
- au moins un équipement en `WARNING` ou `CRITICAL`

> 💡 **Astuce** : ce notebook servira de base à presque tous les scénarios Git du deuxième atelier.

- le statut **Enabled** confirmé

> 💡 **Astuce** : attendre 1 à 2 minutes après la sauvegarde avant de passer à l'étape suivante. Rafraîchir la page du workspace si nécessaire.

⚠️ **Piège** : seul un **Fabric Tenant Admin** peut modifier ces paramètres. Si vous ne voyez pas la section Git integration dans le portail, vous n'avez pas les droits suffisants.

### 9.3 — Créer un Personal Access Token (PAT) sur GitHub

Fabric utilise un PAT pour s'authentifier à GitHub. Il faut le créer avant de configurer la connexion.

1. Aller sur [https://github.com](https://github.com) et se connecter
2. Cliquer sur votre avatar en haut à droite → **Settings**
3. Dans le menu de gauche, descendre jusqu'à **Developer settings**
4. Cliquer **Personal access tokens** → **Tokens (classic)**
5. Cliquer **Generate new token** → **Generate new token (classic)**
6. Renseigner :

| Champ          | Valeur                                      |
| -------------- | ------------------------------------------- |
| **Note**       | `fabric-energy-ops`                         |
| **Expiration** | 90 days (ou selon votre politique interne)  |
| **Scopes**     | cocher `repo` (inclut tous les sous-scopes) |

7. Cliquer **Generate token**
8. **Copier immédiatement le token affiché** — il ne sera plus visible après fermeture de la page

**Ce que vous devez voir à l'écran** :

- un token de la forme `ghp_xxxxxxxxxxxxxxxxxxxx`

⚠️ **Piège** : si vous fermez la page sans copier le token, il faudra en générer un nouveau. Conservez-le temporairement dans un endroit sûr le temps de la configuration.
